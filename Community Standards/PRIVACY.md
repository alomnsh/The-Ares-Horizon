# Privacy Policy: The Ares Horizon

Updated: August 24, 2026

Your privacy is important to us. This Privacy Policy explains how *The Ares Horizon* handles data when you play the game through GitHub Pages or download standalone desktop releases.

## 1. Data We Do Not Collect
*The Ares Horizon* is designed to run directly on your computer or inside your web browser. 
* **No Accounts:** You do not need to create an account or log in to play.
* **No Personal Data:** We do not collect, store, or transmit personal information such as your name, email address, location, or device identifiers.
* **No Tracking:** The game contains no third-party trackers, analytics cookies, or advertisements.

## 2. Local Storage & Game Saves
To keep track of your game (such as settings, terminal logs, or mission progress):
* **Web Version (GitHub Pages):** The game may use your browser's local storage mechanisms to save data. This data stays entirely inside your browser cache and is never sent to servers.
* **Desktop Releases:** Standalone downloads save configuration and progress files locally on your physical machine.

You can delete this data at any time by clearing your browser's site data or deleting the local game save files on your computer.

## 3. Third-Party Infrastructure (GitHub Pages)
Because the web version of the game is hosted using GitHub Pages, GitHub may automatically collect standard web server logs (such as your IP address, browser type, and timestamp) for security purposes and to keep the service running. 

This data is handled strictly by GitHub and is subject to the [GitHub Privacy Statement](https://github.com).

## 4. Contact
If you have any questions about this Privacy Policy, please open a discussion or contact the contributors through GitHub.
